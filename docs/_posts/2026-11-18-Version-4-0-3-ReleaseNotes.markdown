**New in Version 4.0.3**

### Added
- A `--win` option to the `dev:composer` command so a `.bat` version of the toggle-composer.sh script is generated on Windows systems
- Added `toggle-composer.bat` to the `.gitignore` file for the starter package
- Changed theme of user guide to Just the Docs

### Fixed
- Resolved incorrect path in LEMP.md document
- Incorrect spelling of a validator for the `seed:run` command
- Updated current year in the framework's LICENSE file.
